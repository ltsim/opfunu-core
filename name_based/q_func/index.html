    Qing ¶

    Qing(
    ndim=None,
    bounds=None,
    parallel=False,
    fastmath=True,
    dtype=np.float64,
    shift=None,
    prepare=None,
)

    .. [1] Jamil, M. & Yang, X.-S. A Literature Survey of Benchmark Functions For Global Optimization Problems Int. Journal of Mathematical Modelling and Numerical Optimisation, 2013, 4, 150-194.

    .. math::

    f_{     ext{Qing}}(x) = \sum_{i=1}^{n} (x_i^2 - i)^2

    Here, :math:n represents the number of dimensions and :math:x_i \in [-500, 500] for :math:i = 1, ..., n.

    Global optimum: :math:f(x) = 0 for :math:x_i = \pm \sqrt(i) for :math:i = 1, ..., n
